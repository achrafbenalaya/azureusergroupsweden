Community Calendar

Events automatically load from data/events.json. Update the JSON file to publish the latest sessions for Azure Static Web Apps deployments.

How to update the events

Edit the data/events.json file and submit your changes via pull request or direct commit. Each deployment of Azure Static Web Apps will serve the updated list automatically.

Remember to include a descriptive title, ISO 8601 date, start time, event type, image path, and (optional) registration link.
